# Миграции (baseline + инкрементальные)

Миграции для чистой БД с нуля. При старте API применяются автоматически через `golang-migrate`.

## Текущая структура

- **000001–000027** — baseline (схема из clean_baseline, FK и триггеры уже в таблицах)
- **000028+** — будущие инкрементальные миграции

## Запуск

```bash
# Миграции применяются при старте API
go run ./cmd/api
```

## Добавление новых миграций

При изменении схемы:

1. Создайте `000028_description.up.sql` и `000028_description.down.sql`
2. Запустите приложение — миграция применится автоматически

## clean_baseline/

Эта папка — исходники для 000001–000027. При смене baseline обновляйте файлы здесь и перегенерируйте миграции.

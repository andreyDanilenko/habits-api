# Миграция 000022: права и роли

Единая миграция, объединяющая бывшие 022–025. Создаёт схему прав (permission_catalog, workspace_roles, user_role_assignments и др.), системные роли и синхронизирует с user_workspaces.

## Если уже применены старые миграции (022–025)

Сбросить версию и применить новую миграцию:

```bash
# 1. Сбросить версию на 21 (откат 022–025 в журнале migrate)
make migrate-force-21
# или: go run ./cmd/migrate_force

# 2. Запустить приложение (миграция 022 применится автоматически)
go run ./cmd/api/main.go
```

Миграция идемпотентна: при наличии таблиц и данных повторный запуск безопасен (ON CONFLICT, NOT EXISTS).

## PostgreSQL

Миграция использует `EXECUTE PROCEDURE` для триггера (совместимо с PG 10+).

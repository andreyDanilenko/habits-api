## СПЕЦИФИКАЦИЯ ДЛЯ ФРОНТЕНДА
### Этап 2: Модуль активности (Activity Feed)

---

## 1. Общая информация

**Цель:** Реализовать пользовательский интерфейс для просмотра и создания активности в карточках контактов, компаний и сделок.

**Где будет использоваться:**
- Вкладка "Активность" в карточке контакта (`/crm/contacts/:id`)
- Вкладка "Активность" в карточке компании (`/crm/companies/:id`)
- Вкладка "Активность" в карточке сделки (`/crm/deals/:id`)

---

## 2. Типы данных (для фронтенда)

### 2.1. Activity (событие)

```typescript
// То, что приходит с бекенда
interface Activity {
  id: string;
  type: 'note' | 'call' | 'email' | 'task' | 'deal_stage_changed' | 
        'contact_created' | 'contact_updated' | 'company_created' | 
        'company_updated' | 'deal_created' | 'file_attached' | 'message';
  
  entityType: 'contact' | 'company' | 'deal';
  entityId: string;
  
  title: string;              // Краткое описание (обязательно)
  description?: string;        // Полный текст (для заметок)
  
  metadata?: {
    // Для звонков
    callDuration?: number;
    callDirection?: 'in' | 'out';
    callStatus?: 'answered' | 'missed' | 'no_answer';
    callRecording?: string;
    
    // Для писем
    emailSubject?: string;
    emailFrom?: string;
    emailTo?: string[];
    emailAttachments?: Array<{
      name: string;
      size: number;
      url: string;
    }>;
    
    // Для смены этапа
    fromStage?: {
      id: string;
      name: string;
    };
    toStage?: {
      id: string;
      name: string;
    };
    dealValue?: number;
    
    // Для изменений
    changedFields?: Array<{
      field: string;
      fieldLabel: string;
      oldValue: any;
      newValue: any;
    }>;
    
    // Для файлов
    files?: Array<{
      name: string;
      size: number;
      type: string;
      url: string;
    }>;
  };
  
  isImportant?: boolean;
  
  createdBy: {
    id: string;
    name: string;
    avatar?: string;
  };
  createdAt: string;  // ISO
  
  // Флаги для UI
  isEditable?: boolean;   // true только для 'note'
  isDeletable?: boolean;  // true только для 'note'
}
```

### 2.2. Фильтры

```typescript
interface ActivityFilters {
  types?: Activity['type'][];        // Массив типов для фильтрации
  dateFrom?: string;                  // Начало периода (ISO)
  dateTo?: string;                    // Конец периода (ISO)
  importantOnly?: boolean;             // Только важные
  search?: string;                     // Поиск по тексту
}
```

## 3. Компоненты для реализации

### 3.1. ActivityFeed.vue (основной компонент ленты)

**Назначение:** Отображает ленту активности с группировкой по датам, фильтрацией и возможностью добавления новых событий.

**Пропсы:**
```typescript
interface Props {
  entityType: 'contact' | 'company' | 'deal';
  entityId: string;
  canCreate?: boolean;      // По умолчанию true
}
```

**События (emits):**
```typescript
// При создании заметки/звонка
'onCreateNote': (data: CreateNoteDto) => void
'onCreateCall': (data: CreateCallDto) => void
```

**Структура компонента:**

```
┌─────────────────────────────────────────────┐
│ [Кнопки: Заметка | Звонок]  [Фильтр ▼]      │
├─────────────────────────────────────────────┤
│                                             │
│ 🕒 Сегодня                                   │
│                                             │
│ ┌─────────────────────────────────────────┐ │
│ │ [Иконка] 10:23  Заголовок           ⭐ ⋮ │ │
│ │ Детали события...                       │ │
│ │ Автор: Иванов И.                         │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ 🕒 Вчера                                     │
│ ┌─────────────────────────────────────────┐ │
│ │ ...                                      │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ [Загрузить еще]                             │
└─────────────────────────────────────────────┘
```

**Что должен уметь компонент:**
- Загружать активности с пагинацией
- Группировать по датам (сегодня, вчера, на этой неделе, в прошлом месяце, старше)
- Отображать скелетоны во время загрузки
- Показывать сообщение, если активностей нет
- Подгружать новые при скролле или клике "Загрузить еще"
- Применять фильтры

---

### 3.2. ActivityItem.vue (карточка события)

**Назначение:** Отображение одного события в ленте.

**Пропсы:**
```typescript
interface Props {
  activity: Activity;
  showActions?: boolean;    // Показывать кнопки действий (⋮)
}
```

**События:**
- `onToggleImportant` — пометить/снять важность
- `onEdit` — редактировать (для заметок)
- `onDelete` — удалить (для заметок)

**Что должен уметь компонент:**
- Отображать иконку в зависимости от `type`
- Показывать время (ЧЧ:ММ)
- Отображать заголовок и описание
- Для звонков: показывать длительность, направление, результат
- Для писем: показывать тему, отправителя, вложения
- Для смены этапа: показывать с какого на какой
- Для изменений: показывать список измененных полей
- Отображать файлы (иконка, название, размер, ссылка)
- Показывать автора (аватар + имя)
- Если `isImportant` — показывать закрашенную звездочку
- Если `isEditable` — показывать кнопки редактирования/удаления

### 3.3. ActivityFilters.vue (панель фильтров)

**Назначение:** Фильтрация ленты активности.

**Пропсы:**
```typescript
interface Props {
  visible: boolean;          // Показать/скрыть панель
  filters: ActivityFilters;   // Текущие фильтры
}
```

**События:**
- `onApply` — применить фильтры
- `onReset` — сбросить фильтры
- `onClose` — закрыть панель

**Структура:**

```
┌─────────────────────────────────┐
│ ФИЛЬТР АКТИВНОСТИ               │
├─────────────────────────────────┤
│ ТИП СОБЫТИЙ                     │
│ ☑ Все                           │
│ ☑ Заметки (📝)                  │
│ ☑ Звонки (📞)                   │
│ ☑ Письма (✉️)                   │
│ ☑ Сделки (🔄)                   │
│ ☑ Системные (✨)                │
│                                 │
│ ПЕРИОД                          │
│ ○ Все время                     │
│ ○ Сегодня                       │
│ ○ Вчера                         │
│ ○ Последние 7 дней              │
│ ○ Последние 30 дней             │
│ ○ Произвольный                  │
│   [с: ДД.ММ.ГГГГ]               │
│   [по: ДД.ММ.ГГГГ]              │
│                                 │
│ ДОПОЛНИТЕЛЬНО                   │
│ ☑ Только важные                 │
│                                 │
│ ПОИСК                           │
│ [...............................]│
│                                 │
│ [Сбросить]        [Применить]   │
└─────────────────────────────────┘
```

**Что должно работать:**
- Чекбоксы типов событий (можно выбрать несколько)
- Радиокнопки для быстрых периодов
- При выборе "Произвольный" — появляются два поля с датами
- Поиск по тексту (с debounce 300мс)
- Кнопка "Сбросить" очищает все фильтры
- Кнопка "Применить" закрывает панель и применяет фильтры

## 7. Критерии готовности для фронтенда

- [ ] Компонент `ActivityFeed` отображается во всех трех карточках
- [ ] Лента группируется по датам (сегодня, вчера, и т.д.)
- [ ] Иконки соответствуют типам событий
- [ ] Работает пагинация (скролл или кнопка "Загрузить еще")
- [ ] Работают все типы событий из моков
- [ ] Можно создать заметку с текстом и файлами
- [ ] Можно записать звонок
- [ ] Можно пометить событие важным
- [ ] Можно отредактировать/удалить заметку
- [ ] Работает фильтрация по типам
- [ ] Работает фильтрация по датам
- [ ] Работает поиск по тексту
- [ ] Фильтр "Только важные" работает
- [ ] Отображаются все состояния (загрузка, ошибка, пусто)
- [ ] На мобильных устройствах выглядит адекватно

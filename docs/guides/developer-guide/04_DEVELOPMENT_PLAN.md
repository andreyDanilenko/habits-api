## 5. Масштабирование (SCALING_AND_IMPROVEMENT_PLAN)

### 5.1. Готовность к микросервисам

| Модуль | FK на Core | Готовность к выносу |
|--------|------------|----------------------|
| CRM | Нет | ✅ Готов |
| Habits | Да (users, workspaces) | ⚠️ Нужно убрать FK |
| Notes, Journal, Shared | Да | ⚠️ Заменить на UUID |

### 5.2. Варианты разбиения (MICROSERVICES_DECOMPOSITION)

- **Schema-per-Service:** Одна PostgreSQL, разные схемы (auth, workspace, habits, crm, ...)
- **DB-per-Service:** Отдельная БД на сервис
- **BFF/Orchestrator:** Не хранит данных, дергает Core и доменные сервисы

### ⚠️ **КРИТИЧЕСКИЕ ЗАМЕЧАНИЯ (Нужно исправить ДО прода)**

#### 1. **Graceful shutdown отсутствует**
```go
// Сейчас: при перезапуске теряются политики, не сохраненные в БД
func (app *App) Shutdown() {
    // Нужно добавить:
    if err := app.container.Enforcer.SavePolicy(); err != nil {
        log.Printf("Failed to save Casbin policies: %v", err)
    }
}
```

#### 2. **Индивидуальные права не в Casbin**
```go
// Сейчас: проверка требует двух шагов (Casbin + БД)
// После включения боевого режима будет медленно

// Решение: синхронизировать в Casbin
func (s *Service) GrantPermission(ctx context.Context, ...) {
    // 1. Сохраняем в БД для аудита
    // 2. Добавляем в Casbin
    s.enforcer.AddPolicy("user:"+userID, workspaceID, obj, act)
}
```

#### 3. **Нет мониторинга производительности**
```go
// Добавить метрики:
var (
    permissionCheckDuration = prometheus.NewHistogram(...)
    policyChangeCount = prometheus.NewCounter(...)
    cacheHitRatio = prometheus.NewGauge(...)
)
```

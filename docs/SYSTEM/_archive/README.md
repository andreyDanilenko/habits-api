# Архив документов SYSTEM

Файлы здесь **не удалены** — это материалы этапа проектирования и поэтапной фиксации внедрения. Актуальная «операционная правда» по ролям и правам: [../PERMISSIONS/README_PERMISSIONS_ROLES.md](../PERMISSIONS/README_PERMISSIONS_ROLES.md).

---

## Содержимое

| Файл | Что это |
|------|---------|
| `perrmissions.spec.back.v1.md` | Постановка задачи на бэкенд (таблицы, middleware, Casbin). |
| `perrmissions.v1.md` | Короткий системный анализ и план. |
| `perrmissions.v2.md` | Расширенная техспека (SQL, примеры кода). |
| `perrmissions.v3.md` | Анализ существующей БД и план миграций. |
| `PERMISSION_REPORT.PART_1.md` | Отчёт: этап 1 — схема БД и миграции. |
| `PERMISSION_REPORT.PART_2.md` | Отчёт: этап 2 — GORM, Casbin, middleware. |
| `PERMISSION_REPORT.PART_3.md` | Отчёт: этап 3 — термины, жизненный цикл ролей, API. |
| `PERMISSIONS_FRONTEND.v1.md` | Длинный системный анализ фронта/бэка и целевого состояния. |
| `PERMISSIONS_FRONTEND.v2_REVIEW_CHAT.md` | Неформальный разбор/ревью реализации (не спецификация). |
| `TOTAL_STATE_ROLE.v1.md` | Чеклист статуса реализации и технический долг на момент создания. |

**Сводка по внедрению** без разбиения на PART_1–3: [../PERMISSION_REPORT.PART_TOTAL.md](../PERMISSION_REPORT.PART_TOTAL.md).

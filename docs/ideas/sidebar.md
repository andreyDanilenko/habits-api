Другие идеи на будущее (если захочется ещё проще или функциональнее):
Только скроллбар — без градиентов; можно чуть усилить стиль ::-webkit-scrollbar / scrollbar-color, чтобы полоса была заметнее.
Одно поле «Найти модуль» над списком — при 8+ модулях часто удобнее, чем любые кнопки прокрутки.
Двухколоночный режим (иконки модулей узкой полосой + маршруты) — как в IDE, меньше вертикальной «простыни».
Группировка по категориям — короткие подзаголовки вместо одного длинного списка.
Командная палитра (Ctrl/Cmd+K) для перехода по модулям — сайдбар остаётся компактным.
Если нужно, могу следующим шагом либо убрать и градиенты (совсем минимализм), либо добавить компактный поиск только для десктопа.

## 1. Общая концепция системы

### 1.1. Назначение
Корпоративная система управления (ERP) с модульной архитектурой, построенная на принципах мультитенантности и масштабируемости. Каждый модуль может быть включён/отключён независимо, что позволяет гибко настраивать систему под потребности конкретного бизнеса.

### 1.2. Ключевые принципы
- **Мультитенантность** – все данные изолированы по `workspace_id`
- **Модульность** – система состоит из независимых модулей, каждый со своей БД и API
- **Core-модули** – всегда включены (workspace, users, auth)
- **Опциональные модули** – подключаются по лицензии (CRM, Projects, Habits и т.д.)
- **Мягкие связи** – модули не имеют прямых FK друг на друга
- **Масштабируемость** – возможность выноса модулей в отдельные микросервисы

### 1.3. Базовая терминология
| Термин | Определение |
|--------|-------------|
| **Workspace** | Рабочее пространство компании-клиента. Все данные изолированы. |
| **Пользователь** | Физическое лицо, имеющее доступ к системе. Может состоять в нескольких workspace. |
| **Роль** | Набор прав доступа внутри workspace (OWNER, ADMIN, MEMBER, GUEST). |
| **Модуль** | Самостоятельный функциональный блок (CRM, Projects, Habits и т.д.). |
| **Лицензия** | Право на использование модуля (глобальное или для конкретного workspace). |

### 3.1. Назначение
Ядро системы, обеспечивающее мультитенантность, управление рабочими пространствами и пользователями.

### 3.2. Реализованные возможности

**Управление workspace:**
- ✅ Создание workspace

- ✅ Получение текущего workspace
- ✅ Обновление информации о workspace
- ✅ Удаление workspace
- ✅ Переключение между workspace

**Управление участниками:**
- ✅ Получение списка участников workspace

## 12. Права доступа и ролевая модель

### 12.1. Роли в workspace (из user_workspaces.role)

| Роль | Уровень | Типовые права |
|------|---------|---------------|
| **OWNER** | 100 | Полный доступ, управление workspace, удаление |
| **ADMIN** | 80 | Управление настройками, пользователями, модулями |
| **MEMBER** | 50 | Работа с данными (создание, редактирование) |
| **GUEST** | 10 | Только просмотр (read-only) |

### 12.2. Требуется реализовать
